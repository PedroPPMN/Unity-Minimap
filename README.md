# Unity Minimap

RenderTexture minimap with:

- `MapController` — orthographic follower camera
- `MinimapRenderToImage` — feeds a UI `RawImage`
- `MinimapIconTracker` — projects world targets to UI icons
- `PlayerIconNetwork` + `MapNetworkSpawner` — multiplayer-ready icon sync hooks (no NGO hard dependency)
